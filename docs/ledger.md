| D-023 | Decision | A registry domain is promoted by: homepage `<link rel=alternate>` feeds, then robots.txt sitemaps, then common paths only if none; each candidate must parse, have 3+ items, 50%+ links on the same site, and a newest item under 14 days old (undated feeds are accepted and flagged). robots.txt is honoured before anything else is fetched | Cheap, polite, and refuses dead or aggregator feeds | 2026-10-11 | `src/registry/feedDiscovery.ts`, `feedValidation.ts` |
| D-024 | Decision | The worker runs background jobs by itself: GDELT discovery (hourly, 24 h window), registry promotion (hourly, 25 domains, MENA first, needs a contact URL), Wikidata seeding (weekly), retention (daily, opt-in). Each can be turned off (`DISCOVER_EVERY`, `PROMOTE_EVERY`, `SEED_WIKIDATA_EVERY` = `off`) | The system should grow without someone typing commands | 2026-10-11 | `src/ingest/worker.ts`, `job.ts` |
| D-025 | Decision | Aggregators are a built-in list plus the owner's `registry-overrides.yaml`; they are flagged, can be hidden, and are never promoted | Syndication sites would otherwise crowd out outlets that report their own stories | 2026-10-11 | `src/registry/overrides.ts` |
| D-026 | Decision | Country precedence for a domain: owner override, then what Wikidata recorded, then the country-code suffix. `.com` outlets without an override have no country | Suffix alone is wrong for most MENA outlets on `.com`/`.net` | 2026-10-11 | `src/registry/overrides.ts`, `wikidata.ts` |
| D-027 | Decision | Duplicates are flagged at ingest by a headline fingerprint (Arabic-normalised, outlet suffix stripped, 4+ words); the first outlet is kept; search can leave flagged ones out (`dedupe=true`), and aggregations follow | Keeps totals and charts consistent; no query-time collapsing | 2026-10-11 | `src/ingest/titleKey.ts`, `ingestSource.ts` |
| D-028 | Decision | Deployment: one process serves the UI and the API (`/api`); `BASIC_AUTH=user:password` protects everything but `/health`; the API refuses to listen beyond loopback without it; `docker compose --profile app` runs api + worker + OpenSearch | Smallest safe production shape for one analyst team | 2026-10-11 | `src/api/security.ts`, `Dockerfile`, `docker-compose.yml` |
